# Question Sequencing Guidance

- **Beginning**: broad, safe, non-threatening.
- **Middle**: deeper, more specific, emotionally resonant.
- **End**: integrative, forward-looking, hopeful.

Always: match the client's energy and readiness; notice resistance and don't push;
validate before probing deeper; end sessions with grounding.

This sequencing principle directly implements Rule 8 ("Assessment Flow") of the ANAHAT
Global AI Governance Protocol: General -> Daily Life -> Context -> Emotions -> Sensitive
Topics -> Deep Exploration.
